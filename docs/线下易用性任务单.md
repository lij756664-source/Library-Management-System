# 给测试同学的任务单

你将模拟图书管理员，独立完成下面三个任务。可以阅读系统提示、规则说明并自行纠正错误。遇到困难可以说明，但主持人不会告诉你点击步骤。

请等待主持人发放当前任务后再开始；完成时告诉主持人。不要提前阅读下一个任务。

## 任务一 设置规则并确认生效

学校计划采用以下借阅规则，请让它们在系统中生效：

| 规则 | 目标 |
|---|---:|
| 借阅期限 | 21天 |
| 续借次数上限 | 1次 |
| 每次续借天数 | 5天 |
| 每日罚金 | 0.80元 |
| 同时借阅上限 | 4册 |

完成后，请指出系统当前实际生效的五项规则，并说明你怎样判断它们已生效。

---

## 任务二 查看两种范围的统计

请先查看全部历史的借阅统计，再查看2025年1月1日至1月31日的借阅统计。

每个范围都请回答：

1. 热门排行第一本书叫什么，借阅多少次？
2. “QA排行A”分类借阅多少次？
3. 现在展示的是哪个时间范围？

---

## 任务三 理解错误提示并纠正

请依次处理下面两份有错误的业务单。每份都先尝试按原内容提交，说明系统提示了什么、哪些结果实际生效，再改正。

第一份：其他规则沿用任务一，将借阅期限设置为0天。发现问题后，将借阅期限修正为22天并使其生效。

第二份：查询2025年1月31日至2025年1月1日的统计。发现问题后，将范围修正为2025年1月1日至1月31日并完成查询。

完成后，请说明非法配置有没有生效，以及日期出错时系统有没有擅自显示全部历史。
