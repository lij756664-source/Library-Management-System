# 规则、罚金与统计整理说明

## 修改范围

- 规则、罚金、统计服务拆为 IRuleService、IFineService、IStatisticsService，实现在 service/impl 下。Controller 和其他服务依赖接口。
- 规则锁成为 RuleServiceImpl 的私有实现，仅保存规则时使用；保存事务保留。
- 普通借阅 borrowBook 和预约取书 pickup 不再申请规则锁，一次读取完整规则，数量校验、到期时间及快照使用同一份数据，允许使用完整旧版。
- 续借 renewBook、归还 returnBook 不再申请规则锁，沿用借阅记录的续借及罚金快照。原有事务保留。
- 借阅期限快照继续留档，无数据库结构或数据迁移。
- 统计业务集中于 StatisticsServiceImpl，统计 SQL 集中于 StatisticsMapper。罚金汇总复用 IFineService 和现有借阅记录查询。
- 删除 GET /api/statistics/dashboard、/category、/top-books 及其闲置前端请求函数，清理旧分类和排行的服务、Mapper 和 SQL。保留 VO 与 overview 所需逻辑。
- 统计页面通过 getOverview 传递日期；返回结构仍为 dashboard、categoryStats、topBooks，日期只筛选分类与排行。整个查询在同一只读可重复读事务中完成。
- 补充规则、日期、快照及罚金口径的中文注释，整理相关代码格式。

## 组员需知

借还与取书不再因争抢配置行锁而全局排队。此次没有新增借阅记录、库存、预约队列的并发保护，也没有修改这些模块的 SQL 更新条件。模块负责人需核对自身并发要求；历史基于规则锁串行效果的并发结果不能直接用于本版本。

当前仓库前端与脚本不调用三个旧统计入口；仓库外直接调用旧 URL 的客户端需迁移到 overview。保留入口的管理员权限注解不变。

## 验证内容与边界

新增 RuleSnapshotAndStatisticsTest，检查普通借阅/预约取书只读取一次规则，快照与到期时间一致；续借/归还不读取当前配置并沿用历史快照；统计响应结构、全局罚金口径、日期边界传参；三个旧入口无映射而 overview 保留。规则保存测试增加先锁定再整组更新的顺序验证。

前端执行 npm run build。后端使用本机 JDK 17；由于当前环境默认 JDK 8 不支持本项目且 Mockito 自动附加代理启动停滞，验证使用预加载 Byte Buddy agent、Maven -o -DforkCount=0 test。此参数仅用于本轮验证，没有改动 pom.xml 或全局环境。

以上是单元/模拟 HTTP 测试、映射解析和构建验证，不代表真实数据库事务、页面浏览器联调或借还并发安全验证。未连接或修改业务数据库。
