# 界面统一与缺陷修复回归

本轮沿用现有系统的Element Plus组件、page-card、浅蓝主题、圆角、表格条纹、按钮与弹窗，不另设视觉主题。

## 已修改

- 规则页面使用规则名称/设置值/当前生效三列，输入单位对齐；删除每行常驻范围提示，改为规则说明弹窗。
- 未保存修改与有效值分开；成功用系统消息反馈；非法项在输入旁显示中文错误。服务端直接请求也返回中文字段名。
- 结果未知时显示警告并禁止重复保存，可重新查询；未知期间生效列称为“上次确认值”。核实成功后保留输入供对照。规则页自主管理网络反馈，不再叠加英文timeout/Network Error。
- 图书查询增加读者“查看最新规则”只读弹窗；新GET /api/rules/latest允许已登录管理员与读者，返回仅五项规则；保存仍仅管理员。没有公开未登录访问。
- 统计恢复库存、在借、逾期SQL字段；缺失值显示横线而非伪装为0；日期输入和按钮在同一工具栏，原冗长说明删除，结果卡片保留简短范围标签。
- 分类统计改SVG饼图，标分类/次数/占比，细小扇形引线分侧排列，全部类别含0次保留在图例；全0为空态。
- 已还记录剩余/逾期显示横线；罚金统一暂计/最终标签，缴费说明收进提示；删除重复预估字样；零日费归还提示不再宣称一定产生罚款。

## 已验证

- 前端生产构建通过；后端6项自动测试通过（5项规则/罚金/映射/日期筛选测试、1项北京午夜边界测试）。
- 桌面1440×960实际预览规则表格、弹窗、统计工具栏及饼图，无观察到文字重叠，沿用原侧栏和系统主题。
- 管理员非法借期0返回400、“借阅期限的范围为1—90”，未修改配置。
- 读者最新规则200，管理员规则编辑查询403，统计403，规则保存403。
- 统计接口返回库存94、在借4、逾期0，与当前测试数据相符，非null兜底。
- 空数据范围：0个扇形、13个分类图例保留，排行和饼图均为空态；切回历史恢复饼图。
- 读者最新规则弹窗显示30/2/7/0.50/3及旧规则约定说明。
- 用户《活着》已还记录剩余栏为横线，最终2.50元、逾期5天保持。
- 真实超时回归：后端保存31天并扣留响应，同时核实查询断开。页面全中文警告，无英文错误弹窗，保存按钮禁用；恢复连接后重新查询并正常保存回30天。上限3等其他规则保持。见界面回归超时页面记录.json及代理记录。

## 注意

旧测试报告为修复前版本证据。饼图改变了渲染方式，旧25次性能数据不直接冒称是新饼图的性能结论；正式性能验收需要按新图例结构调整探针后复测。3人易用性仍待用户线下执行。手机窄屏仍受原系统固定侧栏宽度限制，本轮桌面风格统一不等于全系统移动适配完成。
