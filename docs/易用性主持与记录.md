1. 暂停其他人的借阅、修改分类和规则等操作，避免改变答案。
2. 记录测试版本、浏览器版本、日期与本次原配置。先前满额测试可能使数量上限为3，这是测试遗留，不是初始默认。
3. 管理员将规则统一恢复为30天、2次、7天、0.50元、5册，并刷新确认。
4. 统计清空日期查询，核对首名QA排行01为12次，QA排行A为57次；查询2025-01-01至2025-01-31，两项也应是12次和57次。若不符，先核查库或数据，不能拿过期答案判错参与者。
5. 回到“图书查询”作为统一起点，关掉弹窗，清除上次输入/错误提示，保持管理员已登录。每个人都从同一位置开始。
6. 除了复位配置和页面，不要删除借阅记录或重跑初始化SQL；本轮任务不需要新增借阅，也不会改变统计数据。

三人之间恢复同样状态即可；同一个人的三个任务按顺序接续，不要在任务一后偷偷复位规则。任务三以任务一的21/1/5/0.80/4为起点。
