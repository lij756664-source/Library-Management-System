## 当前电脑启动

本机application-local.yml已经配置为book_db_current，并保存原连接账号密码。不要重新执行database.sql或快照迁移来“启动项目”。MySQL中已有当前测试数据。

在项目根目录的PowerShell终端启动后端：

```powershell
$env:JAVA_HOME = Join-Path $env:USERPROFILE '.jdks\temurin-17.0.20.1'
mvn -f springboot_back/pom.xml spring-boot:run '-Dspring-boot.run.profiles=local'
```

在另一个终端进入vue_front启动前端：

```powershell
node node_modules/vite/bin/vite.js --host 127.0.0.1
```

打开 http://127.0.0.1:5173/ 。停止服务按Ctrl+C，不会删除数据库记录。

## 组员首次使用

1. 使用JDK17、MySQL8和Node；前端在vue_front执行npm ci安装package-lock锁定的依赖。
2. 将application-local.example.yml复制为同目录application-local.yml，填写自己的库名、账号密码，以local profile启动。不要把个人配置加入Git。没有local文件时也可用环境变量DB_USERNAME、DB_PASSWORD和Spring标准的SPRING_DATASOURCE_URL。
3. 新库初始化依次执行database.sql、user_permission.sql、avatar.sql。reservation.sql是旧库预约补丁，新库无需重复执行；已有数据时不要执行带DROP的初始化脚本。
4. 旧库使用快照迁移前先核对原表结构并备份；脚本会按旧配置补快照再重置五项有效规则。各人库结构若已自行改动，不盲目套用迁移。
5. 数据库内容不在Git提交中。代码存档不能替代数据库备份。
